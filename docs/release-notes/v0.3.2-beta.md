Neuroforge **v0.3.2-beta** improves the editor workflow without changing the audio engine or sound.

### New
- The editor reopens at the size you chose. The size is also saved with the DAW project.
- The FORGE archetype selection stays selected when you reopen the editor or project.
- A current-version label sits below the logo. When a newer GitHub release has a download for your platform, it becomes a button that downloads that release's ZIP directly.

### Downloads
- Windows x64: `Neuroforge-0.3.2-beta-win64.zip` (VST3, CLAP and standalone)
- macOS universal: `Neuroforge-0.3.2-beta-macos.zip` (VST3, AU, CLAP and standalone)
- Linux x86_64: `Neuroforge-0.3.2-beta-linux-x86_64.zip` (VST3, CLAP and standalone)

See the [README](https://github.com/TimbraSuite/Neuroforge#install-beta) for installation steps. DAW projects and presets from v0.3.1-beta remain compatible.
