Fifth beta of **Neuroforge**: a complete redesign of the interface, curve-stepper modulators and a much clearer way to see and edit your modulation. Available as VST3, AU (Logic Pro and GarageBand), CLAP and a standalone app on macOS (universal, Apple Silicon and Intel) and Windows.

### Install on macOS
**Easiest:** paste this into Terminal. It installs everything for your user and avoids the macOS "cannot be opened" warning:
```bash
curl -fsSL https://raw.githubusercontent.com/huuba91/neuroforge/main/install-mac.sh | bash
```
For a manual install, download `Neuroforge-0.3.0-beta-macos.zip` and follow `INSTALL.txt`. You'll need one Terminal command, because these builds are not notarized by Apple.

### Install on Windows
Download `Neuroforge-0.3.0-beta-win64.zip`. Copy `Neuroforge.vst3` to `C:\Program Files\Common Files\VST3\` and/or `Neuroforge.clap` to `C:\Program Files\Common Files\CLAP\`, then rescan in your DAW.

New here? Start with the **[Manual & tutorials](https://github.com/huuba91/neuroforge/blob/main/docs/MANUAL.md)**.

### New
- **Complete UI overhaul:** a new design system with Roboto Condensed typography, and unified knobs with a separate modulation ring (solid = positive, dashed = negative).
- **Colour-coded modulation sources:** pink envelopes, cyan LFOs, purple Motion, white macros, amber steppers. The source strip is grouped, and valid drag targets light up while you drag.
- **FX as effect cards**, with Mix and Motion in the card footer.
- **Toolbar groups**, clearer modulation matrix names, spectrum dB labels, and a **KEYS** button to hide the on-screen keyboard.
- **Output meter** with dB readout, peak hold and clip latch.
- **Curve steppers (2):** Massive Performer-style modulators with up to 16 steps, each with its own curve shape and intensity.
- **Modulation badges on knobs:** drag a badge to set the depth. A "+n" popover lists every modulation route on a knob, with depth bar, invert and remove.
- **INIT button** to reset to a clean starting patch.
- **Typed value entry:** right-click a knob and choose Enter value, or press Enter. Knobs can also be controlled from the keyboard.
- **RESAMPLE:** the NEXT GEN button is renamed to RESAMPLE.
- **About box:** click the logo for a keygen-style About popup.
- **Docs:** updated manual and README, values written the way the plugin displays them.

### Compatibility
Presets and DAW projects saved with v0.2.0-beta still load. The state format has moved to version 2 because the two stepper sources were added to the modulation source list. Older files are converted automatically, so existing modulation routings keep their sources. Patches saved with v0.3.0-beta won't load correctly in older versions.

### Mac testers wanted
The Mac build passes all automated checks on a Mac, but nobody has played it by hand in Logic, GarageBand or Ableton on a Mac yet. Please try it and [report how it runs](https://github.com/huuba91/neuroforge/issues).

### Known limitations
- Not code-signed or notarized. Windows SmartScreen may warn; macOS needs the install script or the one-line `xattr` command.
- Heavily clipped patches can overshoot 0 dBTP by a fraction of a dB between samples. A master limiter handles that.
