Sixth beta of **Neuroforge**, and the first with **Linux** (x86_64): VST3, CLAP and a standalone app. Also available as VST3, AU (Logic Pro and GarageBand), CLAP and a standalone app on macOS (universal, Apple Silicon and Intel) and Windows.

### Install on macOS
**Easiest:** paste this into Terminal. It installs everything for your user and avoids the macOS "cannot be opened" warning:
```bash
curl -fsSL https://raw.githubusercontent.com/TimbraSuite/neuroforge/main/install-mac.sh | bash
```
For a manual install, download `Neuroforge-0.3.1-beta-macos.zip` and follow `INSTALL.txt`. You'll need one Terminal command, because these builds are not notarized by Apple.

### Install on Windows
Download `Neuroforge-0.3.1-beta-win64.zip`. Copy `Neuroforge.vst3` to `C:\Program Files\Common Files\VST3\` and/or `Neuroforge.clap` to `C:\Program Files\Common Files\CLAP\`, then rescan in your DAW.

### Install on Linux
Download `Neuroforge-0.3.1-beta-linux-x86_64.zip` and unzip it. Copy the `Neuroforge.vst3` folder to `~/.vst3/` and/or `Neuroforge.clap` to `~/.clap/`, then rescan in your DAW. The `Neuroforge` standalone can run from anywhere (`chmod +x Neuroforge` if needed). It needs ALSA, FreeType, Fontconfig and X11 at runtime, which most desktop distributions already have; `INSTALL.txt` in the zip lists the Debian/Ubuntu packages.

New here? Start with the **[Manual & tutorials](https://github.com/TimbraSuite/neuroforge/blob/main/docs/MANUAL.md)**.

### New

- **New repository location:** the project moved to [github.com/TimbraSuite/neuroforge](https://github.com/TimbraSuite/neuroforge). Old links redirect.
- **About box:** the logo now links to the new repository.
- Includes everything from v0.3.0-beta: the UI overhaul, curve steppers, modulation badges, RESAMPLE and more.

### Compatibility
Presets and DAW projects saved with v0.3.0-beta load unchanged. The state format has not changed since then.

### Linux and Mac testers wanted
The Linux build passes the unit tests and clap-validator in CI, and the Mac build passes all automated checks on a Mac, but nobody has played either by hand in a DAW yet (Bitwig, Reaper or Ardour on Linux; Logic, GarageBand or Ableton on a Mac). Please try it and [report how it runs](https://github.com/TimbraSuite/neuroforge/issues).

### Known limitations
- Not code-signed or notarized. Windows SmartScreen may warn; macOS needs the install script or the one-line `xattr` command.
- Heavily clipped patches can overshoot 0 dBTP by a fraction of a dB between samples. A master limiter handles that.
