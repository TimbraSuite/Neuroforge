Fourth beta of **Neuroforge**, and the first with **macOS** support: VST3, AU (Logic Pro and GarageBand), CLAP and a standalone app, as a universal binary for Apple Silicon and Intel.

### Install on macOS
**Easiest:** paste this into Terminal. It installs everything for your user and avoids the macOS "cannot be opened" warning:
```bash
curl -fsSL https://raw.githubusercontent.com/huuba91/neuroforge/main/install-mac.sh | bash
```
For a manual install, download `Neuroforge-0.2.0-beta-macos.zip` and follow `INSTALL.txt`. You'll need one Terminal command, because these builds are not notarized by Apple.

### Install on Windows
Download `Neuroforge-0.2.0-beta-win64.zip`. Copy `Neuroforge.vst3` to `C:\Program Files\Common Files\VST3\` and/or `Neuroforge.clap` to `C:\Program Files\Common Files\CLAP\`, then rescan in your DAW.

New here? Start with the **[Manual & tutorials](https://github.com/huuba91/neuroforge/blob/main/docs/MANUAL.md)**.

### New
- **macOS:** VST3, AU, CLAP and Standalone, for macOS 10.15+ (Apple Silicon + Intel).
- **Automated builds:** every release is now built and tested on both Windows and macOS by GitHub Actions. That covers the unit tests, Apple's `auval` Audio Unit validation and the official clap-validator.

### Mac testers wanted
The Mac build passes all automated checks on a Mac, but nobody has played it by hand in Logic, GarageBand or Ableton on a Mac yet. Please try it and [report how it runs](https://github.com/huuba91/neuroforge/issues).

### Known limitations
- Not code-signed or notarized. Windows SmartScreen may warn; macOS needs the install script or the one-line `xattr` command.
- Heavily clipped patches can overshoot 0 dBTP by a fraction of a dB between samples. A master limiter handles that.
